# images/

Put photographs here and reference them from `data/family.js`:

- A person's portrait: set `"photo": "images/thomas-hartwell.jpg"` on that person.
- A gallery photo: add an entry to the `"photos"` list with `"src"`, `"caption"`,
  `"date"` and the `"people"` pictured (by id).

Keep files reasonably small (under ~500 KB each) so the site loads quickly.
The `sample-*.svg` files are placeholders and can be deleted.
